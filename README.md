# BetterCape

A simple Cape System PocketMine-MP plugin made for VeoZaxSMP. Now it's Public for Everyone! Enjoy :D

Originally built for the private **VeoZax SMP** server. Since that server has re-modified, this plugin is now open source.

## Features

- `/bettercape` command and in-game GUI to browse and select capes.
- Cape purchases via **EconomyAPI** (optional: purchases are disabled gracefully if it's not installed).
- Works as a compiled `.phar` **or** as a plain source folder.

## Requirements

- PocketMine-MP (legacy / old-API core)
- PHP 7.0
- EconomyAPI (optional, required only for cape purchases)

## Installation

1. Download the latest `.phar` (or the source folder) from [Releases](../../releases).
2. Drop it into your server's `plugins/` folder.
3. Restart the server.

## Configuration

All settings and in-game messages are in `config.yml`
